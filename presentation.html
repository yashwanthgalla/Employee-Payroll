Problem Statement Member 1
Analysis
The Challenge of Spreadsheet Processing
  • Inaccurate calculations due to manually managed cells and static rates.
  • No verification of inputs (allowing negative payroll and blank names).
  • No validation checks for duplicate employee IDs.
  • Data redundancy and scattering across separate monthly directories.
Slide 3 / 35
Existing Excel System Member 1
Analysis
Existing Process

Traditional spreadsheet workflows require manually typing data, copy-pasting template forms, and relying on formulas that are prone to accidental edits.

Key Disadvantages
  • Accidental cell modifications break calculations.
  • Data entry mistakes go undetected (no runtime checks).
  • No structured audit trail of changes.
Slide 4 / 35
Proposed Automated System Member 1
Analysis
System Features

A decoupled Java 17 console application that automates all payroll operations, checks constraints on entry, and handles database operations in memory.

Core Advantages
  • Zero calculation mismatch.
  • Polymorphic calculations simplify rules.
  • Resilient file parsing avoids runtime failures.

Project Objectives Member 1
Objectives
  • Implement clean object-oriented patterns in Java 17.
  • Achieve salary calculations without complex conditional branches.
  • Utilize HashMap collections for fast key-value lookups.
  • Wrap potential failures in custom exception types.
  • Integrate file reading and writing using modern NIO packages.
  • Format structured payslips and corporate aggregates.

Non-Functional Requirements Member 1
Requirements
  • Performance: $O(1)$ lookup complexity using HashMap.
  • Reliability: Zero application crashes through exception catching.
  • Extensibility: Subclass design simplifies adding new types.
  • Maintainability: Layered separation separates UI from services.
  • Data Integrity: Sanitizes name inputs using regex checks.
  • Resilience: Skips malformed rows during import while continuing execution.

Salary Computation Formulas Member 3
Salary Logic
Regular Employee

Base + 20% Allowance - 10% Tax - Leaves Deduction.

Contract Employee

Base + 10% Bonus - Leaves Deduction. (Exempt Tax).

Intern Trainee

Flat stipend payment. (No tax, no leaves deductions).

Slide 26 / 35
OOP Pillars Demonstration Member 3
OOP Logic
  • Abstraction: Parent class defines abstract salary calculations.
  • Encapsulation: Private fields accessible only via getters.
  • Inheritance: Subclasses share properties of parent class.
  • Polymorphism: Java resolves subclass salary calculations at runtime.

SOLID Design Patterns Member 3
Design
SOLID Principle Implementation Detail
Single Responsibility Calculators handle math, services manage database records.
Open/Closed New employee types extend the base class without code modification.
Liskov Substitution All subtypes replace the parent class without error.
